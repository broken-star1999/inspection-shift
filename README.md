# 质检员的一天

在南渡防护用品厂的出货窗口替五天班。拿到样品和单据，查清依据，再开「通过」「不通过」或「要求审查」。

## 运行

需要 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev
```

打开终端给出的本地地址。坐在出货窗口前，可以拿起桌上的单据、检查托盘里的样品、打内线电话、翻交接簿，再用开单机确认结果。移动鼠标会轻微转动值班员的视线。拖动纸张时，镜头会暂时停住。点击纸张可以拿到台前细看，也可以用 `1`、`2`、`3` 开单。手机竖持时，页面内部自动横置，触屏操作保持稳定视角。右上角提供全屏和音效开关。进度、静音偏好和已看过的结局保存在浏览器内。

## 构建和检查

```sh
npm test
npm run build
npm run preview
```

`src/content.js` 定义来件、单据和对白。`src/engine.js` 处理随机来件、电话线索、存档、交班重审和结局。页面先显示可操作的插画值班室。支持 WebGL 2 的浏览器加载 Three.js，在桌面空闲时切入 `src/workbench-models.js` 中的三维场景。模型在同一台透视相机里，桌上纸张通过射线与台面相交来处理拖动。查看单据和检样细节时使用 HTML 与 CSS。支持 WebGL 1 的浏览器可用 `src/scenery.js` 的 Phaser 场景取得窗外光效。禁用 WebGL 时可以直接在插画值班室完成查验。Web Audio 现场合成翻纸、盖章和铃声。

## EdgeOne Makers

从 GitHub 导入仓库，生产分支选 `main`。项目根目录选仓库根，框架选 Vite，安装命令 `npm ci`，构建命令 `npm run build`，产物目录 `dist`。Node 可在平台提供的版本中选 22.12 以上。站点运行时所需文件均由 `dist` 提供，构建无需环境变量。 [EdgeOne 构建指南](https://pages.edgeone.ai/document/build-guide)

## 美术

`public/art` 包含用内置 ImageGen 为本作制作的像素图，包括窗外厂房、六位人物、备用场景的电话和交接簿，以及护目镜、防护面屏、作业防护手套、防噪耳罩和卡扣插片。检样按正反两面成对裁切为透明 WebP。三维场景中的窗框、工作台、电话、交接簿、检样托盘和开单机由代码建模。纸面上的标题、批号和印记由 Canvas 绘制为纹理。人物、场所与批次均为虚构。
