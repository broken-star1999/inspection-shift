# 质检员的一天

在南渡防护用品厂的出货窗口替五天班。拿到样品和单据，查清依据，再开「通过」「不通过」或「要求审查」。

## 运行

需要 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev
```

打开终端给出的本地地址。鼠标移动时，人物、厂房和玻璃反光有轻微视差。点击纸张可拿到工作台前缘，再翻看或并排核对。桌面也可以用 `1`、`2`、`3` 开单。手机竖持时，页面内部自动横置。右上角提供全屏和音效开关。进度、静音偏好和已看过的结局保存在浏览器内。

## 构建和检查

```sh
npm test
npm run build
npm run preview
```

`src/content.js` 定义来件、单据和对白。`src/engine.js` 处理可复现的随机来件、电话线索、存档状态、交班重审和结局。规则层可以独立运行。`src/scenery.js` 用 Phaser 3.90 绘制窗外像素场景与人物，WebGL 模式启用灯光着色器，Canvas 模式保留基础场景和动画。单据和触控界面使用 HTML 与 CSS。Web Audio 现场合成翻纸、盖章和铃声。

## EdgeOne Makers

从 GitHub 导入仓库，生产分支选 `main`。项目根目录选仓库根，框架选 Vite，安装命令 `npm ci`，构建命令 `npm run build`，产物目录 `dist`。Node 可在平台提供的版本中选 22.12 以上。站点运行时所需文件均由 `dist` 提供，构建无需环境变量。 [EdgeOne 构建指南](https://pages.edgeone.ai/document/build-guide)

## 美术

`public/art` 包含用内置 ImageGen 为本作制作的像素图，包括厂房窗口、六位人物、内线电话、交接簿，以及护目镜、防护面屏、作业防护手套、防噪耳罩和卡扣插片。提示指定了低分辨率方形像素、青绿暖黄的厂房、六种工装和不同检样的材质及轮廓，护目镜有三款。检样按正反两面成对裁切为透明 WebP。包装、表面缺陷、量规和台面单据由界面绘制。人物、场所与批次均为虚构。
